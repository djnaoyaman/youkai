# 妖怪サイトの追加イベント

2026-11-23 更新。既存の Google タグ `G-9ZDWL2GBLG` と `NaoyamanAnalytics` を使い、タグの読み込みや `config` は追加しない。

| イベント | 発生条件 | 送信する値 |
| --- | --- | --- |
| `youkai_category_select` | 近現代妖怪のカテゴリ選択を変更したとき、カテゴリ別索引へのリンクを選んだとき、分類図から分類へ移動したとき | `category_id` は定義済みの固定 ID、`selection_source` は `category_filter` / `category_link` / `category_section` |
| `encyclopedia_navigate`（既存を拡張） | サイト内の図鑑・作品・主要ページを選択したとき | 従来の `content_group` に `content_id` と `selection_source`（`navigation` / `content`）を追加 |

- 同じカテゴリ選択で `encyclopedia_navigate` は送らない。選択欄の同じ値への変更、現在のページ、通常のページ内リンク、外部リンク、ダウンロードは追加計測しない。
- 分類図のスムーズ移動は移動先が存在し、既存の移動処理が始まった時点で計測する。動きを減らす設定では通常のリンク選択を計測する。
- 共通スクリプトを二度読み込んでも追加リスナーは重複登録しない。分類図の同じ操作も一度だけ送る。
- 既存の地域展開、読書表示、地図フィルター、共有のイベントは維持する。音声操作の UI がないため音声イベントは追加しない。
- 本番ホストだけで送信し、`ga-disable-G-9ZDWL2GBLG` を尊重する。送信失敗はページ操作に影響させない。
- 検索語、本文、入力内容、画像は送信しない。カテゴリは固定 ID、作品は公開 URL の英数字スラッグだけを使う。`page_location` と `page_referrer` のクエリ・フラグメントは除く。
- 計測処理は共通の `script.js` に集約。カテゴリ名・所属・生成 HTML は変更していないためカテゴリ生成元の再生成は不要。

## 確認

公開前に JavaScript の構文、カテゴリ・図鑑選択の排他、重複登録防止、分類図の移動成功時だけの送信、固定 ID、クエリ除外、オプトアウトを局所実行で確認する。公開後は既存の Pages デプロイ成功と代表箇所の最小確認にとどめる。
